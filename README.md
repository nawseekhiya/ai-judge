# AI Judge

AI Judge is an intern project: a web app where two sides upload arguments or documents and an AI judge (Gemini API or mock fallback) issues a verdict.

Structure:

- `/client` - Next.js 15 frontend (App Router, TypeScript, Tailwind)
- `/server` - Express + TypeScript backend (API, file uploads, AI integration stub)

See `/client/README.md` and `/server/README.md` for per-service instructions.
